## 報修清單篩選

清單預設顯示最近 20 筆報修，依建立時間由新到舊排列。點選「全部」、「高」、「中」或「低」可篩選已載入的資料，切換時不會再查詢資料庫。選取的按鈕會高亮，緊急程度為「高」的報修會顯示紅色標籤。

## 安裝到主畫面

以 HTTPS 開啟報修登記網頁。Android 可在 Chrome 選單選擇「安裝應用程式」或「加到主畫面」，iPhone 可在 Safari 的分享選單選擇「加入主畫面」。桌面 Chrome 或 Edge 可使用網址列的安裝圖示或瀏覽器選單。

首次連線開啟網頁後，離線重新開啟會看到連線提示。報修送出與清單查詢需要網路，報修內容不會存入離線快取。
