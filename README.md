# 開發部新產品開發／報價

業務提出新產品開發或報價需求時，以這個網頁登記需求內容，開發部可在同一頁查看最近的需求與報價時程。

## 表單內容

| 區塊 | 欄位 |
| --- | --- |
| 產品項目 | 產品名稱；產品類別：模板、系統架、零件、其它項目（選「其它」須填說明） |
| 業務提供資訊 | 業務人員、需求材質、需求數量、表面處理種類、加工關卡（幾道加工製程） |
| 表面處理種類 | 不需表面處理、熱浸鍍鋅、電鍍（吊電）、電鍍（爐桶）、機械鍍鋅、噴漆 |
| 製圖與報價 | 是否需要製圖、是否需要報價（至少選一項） |
| 報價內容 | 樣品報價、量產報價（依量產數量分級，最多 5 個級距）、報價需求時間 |
| 報價需求總天數 | 業務提供資訊 → 確認資訊可用性 → 完成報價評估及成本計算 → 提供報價給業務，四個日期須依序排列，系統自動計算總天數 |

選「不需報價」時，報價內容與時程區塊會隱藏，不會送出。若預計提供報價的日期晚於報價需求時間，表單和清單都會顯示提醒。

## 需求清單

清單預設顯示最近 20 筆需求，依建立時間由新到舊排列。點選「全部」、「模板」、「系統架」、「零件」或「其它」可篩選已載入的資料，切換時不會再查詢資料庫。

## 資料庫設定

在 Supabase 專案的 SQL Editor 執行 [`supabase/schema.sql`](supabase/schema.sql)，建立 `new_product_requests` 資料表。資料表啟用資料列安全（RLS），未登入的訪客只能新增與讀取，不能修改或刪除；處理狀態預設為「待處理」。Supabase 網址與公開金鑰設定在 `config.js`。

## 安裝到主畫面

以 HTTPS 開啟網頁。Android 可在 Chrome 選單選擇「安裝應用程式」或「加到主畫面」，iPhone 可在 Safari 的分享選單選擇「加入主畫面」。桌面 Chrome 或 Edge 可使用網址列的安裝圖示或瀏覽器選單。

首次連線開啟網頁後，離線重新開啟會看到連線提示。需求送出與清單查詢需要網路，需求內容不會存入離線快取。
